פרק 3 · בדיקות סטטיות, סוגי סקירה ותפקידים

בחדר מונחים ארבעה תיאורים של סקירות שנערכו השנה:

  1. הכותב מוביל את הישיבה ומציג את המסמך; המטרה העיקרית היא להגיע להבנה משותפת ולאסוף משוב.
  2. סקירה רשמית מאוד: יש תהליך מוגדר, תפקידים מוגדרים, איסוף מדדים, ומטרה למצוא כמה שיותר פגמים. הכותב אינו מנחה את הישיבה.
  3. עמית שולח הערות בצ'אט על מסמך הדרישות, בלי תהליך מתועד.
  4. מומחים טכניים סוקרים עיצוב ארכיטקטוני כדי להגיע לקונצנזוס ולהחליט על פתרון טכני.

וקטע הקוד הזה עבר סקירה סטטית, בלי להריץ אותו:

int fee(int days) {
    int total;                 // line 2
    int unused = 7;            // line 3
    if (days > 0) {
        total = days * 40;
        return total;
        total = total + 5;     // line 7
    }
    return total;              // line 9
}
התאימו סוג סקירה לכל תיאור, לפי הסדר 1–4. השתמשו בקודים: I = בלתי פורמלית · W = Walkthrough · T = סקירה טכנית · N = Inspection.
תשובה: WNIT

1 — Walkthrough (W): הכותב מוביל, מטרה של הבנה משותפת. 2 — Inspection (N): הפורמלית ביותר, תפקידים ומדדים. 3 — בלתי פורמלית (I). 4 — סקירה טכנית (T): קונצנזוס והחלטה טכנית. התשובה: WNIT.

בקוד יש שלוש בעיות שניתנות לגילוי בניתוח סטטי. כתבו את מספרי השורות שלהן בסדר עולה.
תשובה: 379

שורה 3: משתנה שמוגדר ולא בשימוש (unused). שורה 7: קוד שלא ניתן להגיע אליו (Unreachable) — הוא אחרי return. שורה 9: מוחזר משתנה שלא אותחל כש-days ≤ 0. ניתוח סטטי מוצא את כל אלה בלי להריץ את הקוד. התשובה: 379.

פרק 6 · כלי בדיקה, יתרונות וסיכונים באוטומציה

בארון הכלים ארבעה כלים עם תוויות שנפלו. התיאורים:

  1. מנהל את מקרי הבדיקה, מקשר אותם לדרישות ולפגמים ומפיק דוחות התקדמות.
  2. מנתח קוד בלי להריץ אותו ומתריע על הפרות של כללי קידוד ועל קוד מת.
  3. מדמה אלפי משתמשים בו-זמנית כדי למדוד זמני תגובה.
  4. מריץ תסריטים אוטומטיים שלוחצים על כפתורים בדפדפן ומשווים לתוצאה הצפויה.

התוויות: ‏A · כלי ניהול בדיקות · B · כלי לבדיקות ביצועים ועומסים · C · כלי ניתוח סטטי · D · כלי להרצת בדיקות אוטומטיות.

ומתחת לארון, פתק של סמנכ"ל: קנינו כלי אוטומציה, אז מעכשיו לא צריך בודקים, הכלי יבדוק הכול לבד, והוא לא דורש תחזוקה.

כתבו את התווית המתאימה לכל תיאור, לפי הסדר 1–4.
תשובה: ACBD

1 — ניהול בדיקות (A). 2 — ניתוח סטטי (C). 3 — ביצועים ועומסים (B). 4 — הרצת בדיקות אוטומטיות (D). התשובה: ACBD.

כמה סיכונים של אוטומציה, מתוך הרשימה בסילבוס, מגולמים בפתק של הסמנכ"ל? (ציפיות לא מציאותיות · הערכת חסר של מאמץ התחזוקה · הסתמכות יתר על הכלי)
