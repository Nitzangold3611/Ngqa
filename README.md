## מבנה
- `site/` – האתר שמתפרסם (עמוד ראשי + `courses/<קורס>/`), כולל `auth.js` (התחברות), `admin/` (דף ניהול) ו-`netlify/functions/` (פונקציות שרת).
- `*/scripts/` – סקריפטי בנייה (יצירת המצגות וחיתוך השקפים לאתר).
- `genai/spec/` – תמלול השקפים (JSONL לכל פרק), המקור לבניית מצגות CT-GenAI.
- `genai/icons/` – אייקונים למצגות.
- `scripts/make_search.py` – בונה את אינדקס החיפוש (`site/courses/<קורס>/search.json`) מהמצגות והתרגילים.
- `ctfl/exams/` – מבחני CTFL לדוגמא (ערכות A–D): השאלות וההסברים (`qA.py`…`qD.py`) והבנייה; `ctfl/scripts/add_exams.py` מוסיף אותם לאתר.
- `site/wm.js` – watermark אישי על הורדות PDF והדפסה (נטען מ-`auth.js` בעמודי הקורסים; `site/vendor/pdf-lib.min.js`, רישיון MIT).
- `genai/redirect/` – האתר הישן ngqa-genai, מפנה לאתר המאוחד.
- `CHANGELOG.md` – יומן שינויים.

קבצי ה-PPTX המקוריים והמעוצבים נשמרים בכונן NGQA ולא בריפוזיטורי.

## פריסה
כל push ל-`main` מתפרסם אוטומטית ב-Netlify:
- ngqa-ctfl40 (האתר המאוחד, courses.ngqa.net) → Base directory: `site`
- ngqa-genai (הפניה בלבד) → Base directory: `genai/redirect`
