## בדיקות
לפני כל העלאה מריצים את כל הבדיקות ומצרפים את הדוח:
```
npm test                 # הכול מקומית (לא נוגע באתר ובתלמידים)
npm run test:live        # + בדיקות קריאה בלבד על https://courses.ngqa.net
```
- `tests/integrity.test.mjs`: תוכן הקורסים (פרקים, שקפים, תרגילים מול העמוד הראשי), קבצים חסרים, קישורים שבורים, אינדקס החיפוש, נעילת כל קורס ב-`_redirects`, בדיקת הרשאה בכל עמוד קורס, כותרות אבטחה, סודות בקוד, עברית/RTL, כפתור וואטסאפ, עקביות גרסה ותיעוד.
- `tests/functions.test.mjs`: פונקציית הניהול (הזמנה, הרשאות, חסימה, שליחה חוזרת, איפוס, מחיקה, הגנות על המנהל), הוק הכניסה, ונעילת הקורסים בשרת (בלי התחברות, הרשאה לקורס אחד, מנהל, טוקן מזויף או שפג).
- `tests/e2e/`: בדיקות דפדפן (Playwright): התחברות ושגיאות, מי רואה איזה קורס, גישה ישירה לכתובת, קישור עמוק אחרי התחברות, חסום, שכחתי סיסמה, הזמנה והשלמת הרשמה, פתיחה וסגירה של קורס בדף הניהול (נכנס לתוקף ברענון), חסימה ומחיקה, ניווט בשקפים, חיפוש, וואטסאפ, טלפון. כל שגיאת JavaScript מכשילה את הבדיקה.
- `tests/preview/`: בדיקות קריאה בלבד על אתר אמיתי (`BASE_URL`): נעילת קורסים, הרשמה בהזמנה בלבד, פונקציית ניהול נעולה, כותרות.
- הבדיקות המקומיות רצות על תחליף מקומי של Netlify ו-Netlify Identity (`tests/support/`), שמריץ את קוד הפונקציות האמיתי.
- `.github/workflows/qa.yml`: מריץ את כל הבדיקות על כל Pull request, ואת בדיקות האתר האמיתי על כל Deploy Preview.
- דוח: `tests/reports/latest.html` (מלא, עם צילומי מסך, לא נשמר בגיט) ו-`tests/reports/v<גרסה>.md` (נשמר בגיט עם כל גרסה).

דרישות מקומיות: Node 20+, Python 3 עם `pytest` ו-`playwright` (`pip install pytest playwright && playwright install chromium`).

## מבנה
- `site/` – האתר שמתפרסם (עמוד ראשי + `courses/<קורס>/`), כולל `auth.js` (התחברות), `admin/` (דף ניהול) ו-`netlify/functions/` (פונקציות שרת).
- `*/scripts/` – סקריפטי בנייה (יצירת המצגות וחיתוך השקפים לאתר).
- `genai/spec/` – תמלול השקפים (JSONL לכל פרק), המקור לבניית מצגות CT-GenAI.
- `genai/icons/` – אייקונים למצגות.
- `scripts/make_search.py` – בונה את אינדקס החיפוש (`site/courses/<קורס>/search.json`) מהמצגות והתרגילים.
- `genai/redirect/` – האתר הישן ngqa-genai, מפנה לאתר המאוחד.
- `CHANGELOG.md` – יומן שינויים.

קבצי ה-PPTX המקוריים והמעוצבים נשמרים בכונן NGQA ולא בריפוזיטורי.

## פריסה
כל push ל-`main` מתפרסם אוטומטית ב-Netlify:
- ngqa-ctfl40 (האתר המאוחד, courses.ngqa.net) → Base directory: `site`
- ngqa-genai (הפניה בלבד) → Base directory: `genai/redirect`
