College

סטודנטים, קורסים וציונים · 12 שאלות

שלוש טבלאות: Student (ID, First, Last), Course (Code, Title) ו-Grade (ID, Code, Grade). מריצים את קובץ ההקמה במסד נתונים חדש ופותרים.

StudentCourseGrade
⬇ קובץ הקמה (college_setup.sql)

מחבר השאלון: קובי יונסי

  1. מצא את שמו הפרטי ומספר הסטודנט של מר בראון (Brown).
    הצג פתרוןהסתר פתרון
    SELECT First, ID
FROM Student
WHERE Last = 'Brown';
  2. סדר מחדש את טבלת הסטודנטים בסדר יורד לפי מספר הסטודנט ובסדר עולה לפי שם המשפחה. דאג שהעמודות First ו-Last יוצגו בשמות First Name ו-Last Name.
    הצג פתרוןהסתר פתרון
    SELECT ID, First AS [First Name], Last AS [Last Name]
FROM Student
ORDER BY ID DESC, Last ASC;
  3. עדכן לתלמידה S104 שם משפחה חדש בעקבות נישואיה: Jones-Abutbul.
    הצג פתרוןהסתר פתרון
    UPDATE Student
SET Last = 'Jones-Abutbul'
WHERE ID = 'S104';
    הערה: שימו לב: העמודה Last מוגדרת char(10) והשם החדש ארוך יותר, ולכן תתקבל שגיאת קיצור (String or binary data would be truncated). אפשר להגדיל קודם את העמודה: ALTER TABLE Student ALTER COLUMN Last varchar(20);
  4. מצא את ממוצע הציונים שהתקבלו בקורס תכנות 2.
    הצג פתרוןהסתר פתרון
    SELECT AVG(G.Grade) AS AvgGrade
FROM Grade AS G
INNER JOIN Course AS C ON G.Code = C.Code
WHERE C.Title = 'Programming 2';
    הערה: תוקן: AVEG → AVG
  5. הכנס תלמיד חדש למערכת: S108, תומר (לא מסר שם משפחה בשלב זה).
    הצג פתרוןהסתר פתרון
    INSERT INTO Student (ID, First, Last)
VALUES ('S108', 'Tomer', NULL);
  6. מחק לתלמיד S104 את הציון בלבד מהרשימה הרלוונטית.
    הצג פתרוןהסתר פתרון
    UPDATE Grade
SET Grade = NULL
WHERE ID = 'S104';
  7. מצא מהו הציון הגבוה ביותר שהתקבל בקורס ניהול פרויקטים.
    הצג פתרוןהסתר פתרון
    SELECT MAX(G.Grade) AS MaxGrade
FROM Grade AS G
INNER JOIN Course AS C ON G.Code = C.Code
WHERE C.Title = 'Project Mgmt';
  8. מצא את הציונים שקיבלו כל הסטודנטים ששמם הפרטי הוא John.
    הצג פתרוןהסתר פתרון
    SELECT G.Grade
FROM Grade AS G
INNER JOIN Student AS S ON G.ID = S.ID
WHERE S.First = 'John';
  9. מצא את סכום כל הציונים שהתקבלו יחד מהתלמידים S103 עד S107 (ללא התלמיד S104).
    הצג פתרוןהסתר פתרון
    SELECT SUM(Grade) AS TotalGrades
FROM Grade
WHERE ID BETWEEN 'S103' AND 'S107' AND ID <> 'S104';

-- או:
-- WHERE ID IN ('S103', 'S105', 'S106', 'S107');
    הערה: תוקן: בקובץ המקורי הופיעו שתי הוראות WHERE ברצף; השנייה הועברה להערה כחלופה
  10. מצא את שמות המשפחה של כל הסטודנטים, ועבור אלו שנבחנו הצג לצד השם את קוד הקורס שבו נבחנו.
    הצג פתרוןהסתר פתרון
    SELECT S.Last, G.Code
FROM Student AS S
LEFT JOIN Grade AS G ON G.ID = S.ID;
  11. מצא את שם הקורס שיש בו נכשלים (נכשל = ציון נמוך מ-60).
    הצג פתרוןהסתר פתרון
    SELECT DISTINCT C.Title
FROM Course AS C
INNER JOIN Grade AS G ON G.Code = C.Code
WHERE G.Grade < 60;
    הערה: נוסף DISTINCT כדי שכל קורס יופיע פעם אחת
  12. מצא את ממוצע הציונים של התלמיד John Good.
    הצג פתרוןהסתר פתרון
    SELECT AVG(G.Grade) AS AvgGrade
FROM Grade AS G
INNER JOIN Student AS S ON G.ID = S.ID
WHERE S.First = 'John' AND S.Last = 'Good';

Party
⬇ קובץ הקמה (party_setup.sql)
  1. שלוף את שמותיהם בלבד של מי שאישר הגעה למסיבה (כלומר כל מי שמופיע בטבלה).

  2. שלוף את שמם וגילם של כל מי שעדכן באיזה אמצעי תחבורה יגיע.

    SELECT Name, age
FROM party
WHERE transport IS NOT NULL
  3. אתר את כל פרטי האנשים שמגיעים מנתניה.
    הצג פתרוןהסתר פתרון
    SELECT *
FROM party
WHERE city = 'Netanya'
  4. אתר את פרטי כל מי שמגיע במונית או ברכבת.
    הצג פתרוןהסתר פתרון
    SELECT *
FROM party
WHERE transport IN ('train', 'taxi')
  5. אתר את פרטי כל הגברים במסיבה.
    הצג פתרוןהסתר פתרון
    SELECT *
FROM party
WHERE gender = 'm'
  6. אתר את כל פרטי שלושת המבוגרים ביותר במסיבה.
    הצג פתרוןהסתר פתרון
    SELECT TOP 3 *
FROM Party
ORDER BY Age DESC;
    הערה: השאלה מבקשת את כל הפרטים, לכן * במקום age בלבד
  7. אתר את כל פרטי מי שמגיע למסיבה ואינו ממחלקת מכירות.
    הצג פתרוןהסתר פתרון
    SELECT *
FROM party
WHERE department != 'sales'
  8. אתר את גילו ושמו של מי שלא מסר אם הוא מעוניין בארוחה בשרית או חלבית.
    הצג פתרוןהסתר פתרון
    SELECT *
FROM party
WHERE food IS NULL
  9. אתר שם, גיל ומין של מי שלא ידוע איך הוא מתכונן להגיע למסיבה.
    הצג פתרוןהסתר פתרון
    SELECT name, age, gender
FROM party
WHERE transport IS NULL
  10. אתר את מחלקתו של מי שמעוניין לשתות יין או וודקה, או שלא מסר שום הודעה בעניין השתייה.
    הצג פתרוןהסתר פתרון
    SELECT Department
FROM Party
WHERE Drink1 IN ('Wine', 'Vodka') OR Drink2 IN ('Wine', 'Vodka')
   OR (Drink1 IS NULL AND (Drink2 IS NULL OR Drink2 = ''));
    הערה: לא מסר הודעה על שתייה = שני המשקאות ריקים (NULL או מחרוזת ריקה)
  11. אתר את שמו, ארוחתו, מחלקתו וגילו של מי ששותה בירה.
    הצג פתרוןהסתר פתרון
    SELECT name, food, department, age
FROM party
WHERE drink1 = 'beer' OR drink2 = 'beer'
  12. אתר את שמו וגילו של כל מי ששותה וודקה, מים או פפסי.
    הצג פתרוןהסתר פתרון
    SELECT name, age
FROM party
WHERE drink1 IN ('vodka', 'water', 'pepsi') OR drink2 IN ('vodka', 'water', 'pepsi')
  13. אתר את מינו של מי ששותה בירה ופפסי יחד.
    הצג פתרוןהסתר פתרון
    SELECT gender
FROM party
WHERE drink1 IN ('beer', 'pepsi') AND drink2 IN ('beer', 'pepsi')
  14. אתר את שמו ועיר מגוריו של כל מי שדיווח מה הוא רוצה לשתות.
    הצג פתרוןהסתר פתרון
    SELECT name, city
FROM party
WHERE drink1 IS NOT NULL OR drink2 IS NOT NULL
  15. מיין את הטבלה בסדר עולה לפי גיל המשתתפים.
    הצג פתרוןהסתר פתרון
    SELECT *
FROM party
ORDER BY age
  16. הצג את שם המשתתפים והמשקאות שהזמינו, עבור כל מי שמגיע מעיר ששמה מכיל את האות A.
    הצג פתרוןהסתר פתרון

  17. שלוף את כל מי ששמו מסתיים באות I באנגלית.
    הצג פתרוןהסתר פתרון

  18. הצג את גילו של כל מי שמגיע ממחלקת מכירות והזמין ארוחה בשרית.

  19. שלוף את המשקאות של כל מי שאינו ממחלקת הנהלה.
    הצג פתרוןהסתר פתרון
    SELECT drink1, drink2
FROM party
WHERE department != 'management'
  20. שלוף את שם המשתתף ומחלקתו של כל מי שמעל גיל 30.
    הצג פתרוןהסתר פתרון
    SELECT name, department

  21. שלוף את שמו של כל מי שמתחת לגיל 60 ומגיע ברכב או ברכבת.
    הצג פתרוןהסתר פתרון
    SELECT name

  22. ערוך את הטבלה בסדר חדש לפי שם העיר בסדר עולה.
    הצג פתרוןהסתר פתרון
    SELECT *

  23. הצג את המשקה שהזמין מי שלא דיווח איך יגיע וגם לא דיווח מה ירצה לאכול.
    הצג פתרוןהסתר פתרון
    SELECT drink1, drink2

WHERE transport IS NULL AND food IS NULL
  24. שלוף את אמצעי התחבורה והגיל של כל מי שלא דיווח על הארוחה הרצויה.

    SELECT transport, age

WHERE food IS NULL
  25. שלוף את המזון, המשקה, השם והגיל של כל מי שאינו ממחלקת הנהלה או מכירות.

    SELECT Name, Food, Drink1, Drink2, Age

  26. שלוף את סוג המשקה והארוחה של כל מי ששמו דודי או מירב.

  27. שלוף את שמות הנשים שגילן בין 20 ל-40.
    הצג פתרוןהסתר פתרון
    SELECT name
FROM party
WHERE gender = 'f' AND age BETWEEN 20 AND 40
  28. שלוף את שם מי שמעל גיל 18, שייך למחלקת מכירות ומעוניין לשתות מים במסיבה.

    SELECT Name

WHERE Age > 18 AND Department = 'sales'
  AND (Drink1 = 'water' OR Drink2 = 'water');

  29. שלוף את שמות כל הנשים שמגיעות בכל אמצעי למעט אופניים.

Human Resources

מסד HR: עובדים, מחלקות, תפקידים ומיקומים · 15 שאלות

תרגיל על הסכמה של מסד HR (בלי קובץ הקמה): REGIONS, COUNTRIES, LOCATIONS, DEPARTMENTS, JOBS, EMPLOYEES ו-JOB_HISTORY. כותבים את השאילתות לפי מבנה הטבלאות.

REGIONS (region_id, region_name)COUNTRIES (country_id, country_name, region_id)LOCATIONS (location_id, street_address, postal_code, city, state_province, country_id)DEPARTMENTS (department_id, department_name, manager_id, location_id)JOBS (job_id, job_title, min_salary, max_salary)EMPLOYEES (employee_id, first_name, last_name, email, phone_number, hire_date, job_id, salary, commission_pct, manager_id, department_id)JOB_HISTORY (employee_id, start_date, end_date, job_id, department_id)

מחבר השאלון: קובי יונסי

  1. מצא את 3 המשכורות הגבוהות ביותר מתוך עמודת משכורות המינימום, כנה את העמודה MIN_MAX_SALARY, וסדר בסדר יורד (בלי נהגים ומורים).
    הצג פתרוןהסתר פתרון
    SELECT TOP 3 min_salary AS MIN_MAX_SALARY
FROM JOBS
WHERE job_title NOT IN ('Drivers', 'Teachers')
ORDER BY min_salary DESC, job_id DESC;
    הערה: תוקן ל-T-SQL: LIMIT 3 → TOP 3
  2. שלוף את שם העובד, שם משפחתו וכותרת התפקיד שלו.
    הצג פתרוןהסתר פתרון
    SELECT E.first_name, E.last_name, J.job_title
FROM EMPLOYEES AS E
INNER JOIN JOBS AS J ON E.job_id = J.job_id;
  3. עדכן בטבלת המיקומים לכולם עיר = ערך ריק, למעט המיקומים בקוד מדינה 972.
    הצג פתרוןהסתר פתרון
    UPDATE LOCATIONS
SET city = NULL
WHERE country_id <> '972';
  4. הצג את מספרי המנהלים של העובדים בחברה, ועבור אלו שרשומה להם מחלקה הוסף גם את מספר המחלקה.
    הצג פתרוןהסתר פתרון
    SELECT manager_id, department_id
FROM EMPLOYEES;
    הערה: תוקן שם העמודה managr_id → manager_id
  5. מצא את כל פרטי המדינות שמופיעות גם בטבלת המיקומים.
    הצג פתרוןהסתר פתרון
    SELECT *
FROM COUNTRIES
WHERE country_id IN (SELECT country_id FROM LOCATIONS);
    הערה: תוקן: שמות טבלה ועמודה שגויים, והצירוף המקורי החזיר כל מדינה כמה פעמים
  6. מצא את מספר התפקיד ומספר המחלקה של כל העובדים שהתחילו לעבוד בשנת 2009.
    הצג פתרוןהסתר פתרון
    SELECT job_id, department_id
FROM EMPLOYEES
WHERE YEAR(hire_date) = 2009;
    הערה: הוחלף LIKE '%2009%' ב-YEAR(), שעובד נכון על עמודת תאריך
  7. הצג את כל מספרי האזורים, ועבור אזורים שמחוברים למדינות הצג גם את שמות המדינות. סדר לפי שם המדינה בסדר יורד.
    הצג פתרוןהסתר פתרון
    SELECT R.region_id, C.country_name
FROM REGIONS AS R
LEFT JOIN COUNTRIES AS C ON R.region_id = C.region_id
ORDER BY C.country_name DESC;
    הערה: תוקנו שמות הטבלאות
  8. הצג את ממוצע המשכורות של העובדים בעמודה אחת.
    הצג פתרוןהסתר פתרון
    SELECT AVG(salary) AS AvgSalary
FROM EMPLOYEES;
  9. מצא כמה רשומות קיימות בטבלת המדינות.
    הצג פתרוןהסתר פתרון
    SELECT COUNT(*) AS CountriesCount
FROM COUNTRIES;
  10. מצא את הערך המינימלי של עמודת המשכורת המקסימלית בטבלת התפקידים.
    הצג פתרוןהסתר פתרון
    SELECT MIN(max_salary)
FROM JOBS;
  11. מצא את שמות המשפחה של 5 העובדים שמשתכרים הכי גבוה בחברה.
    הצג פתרוןהסתר פתרון
    SELECT TOP 5 last_name
FROM EMPLOYEES
ORDER BY salary DESC;
    הערה: תוקן ל-T-SQL: LIMIT 5 → TOP 5
  12. מצא את סכום כל המשכורות שהחברה משלמת לעובדים וכנה את העמודה TOTAL.
    הצג פתרוןהסתר פתרון
    SELECT SUM(salary) AS TOTAL
FROM EMPLOYEES;
  13. מצא את תאריך סיום העבודה ומספר המחלקה של כל העובדים שמסיימים לעבוד השנה.
    הצג פתרוןהסתר פתרון
    SELECT end_date, department_id
FROM JOB_HISTORY
WHERE YEAR(end_date) = YEAR(GETDATE());
    הערה: השנה הקבועה 2021 הוחלפה בשנה הנוכחית
  14. מצא את שם המחלקה וקוד המדינה עבור מחלקות שממוקמות בעיר ברצלונה.
    הצג פתרוןהסתר פתרון
    SELECT D.department_name, L.country_id
FROM DEPARTMENTS AS D
INNER JOIN LOCATIONS AS L ON D.location_id = L.location_id
WHERE L.city = 'Barcelona';
    הערה: תוקן שם העמודה locatin_id
  15. מצא את מספר העובד, העמלה שהוא מקבל, ומספר ושם המחלקה שהוא מנהל, רק עבור מנהלים בפועל.
    הצג פתרוןהסתר פתרון
    SELECT E.employee_id, E.commission_pct, D.department_id, D.department_name
FROM DEPARTMENTS AS D
INNER JOIN EMPLOYEES AS E ON D.manager_id = E.employee_id;
    הערה: הוחלף הפתרון: מנהל בפועל הוא העובד שמופיע ב-DEPARTMENTS.manager_id
